How It Works

6-stage forensic pipeline powered by 4 neural networks

STEP 01
🎞️
Frame Extraction
Video is uniformly sampled into 15 key frames for temporal coverage without losing important motion data.
STEP 02
👤
Face + Lip Detection
MTCNN detects and crops facial regions. A secondary crop isolates the mouth/lip area for LipForensics analysis.
STEP 03
⚡
EfficientNet-B4
Compound-scaled CNN extracts deep visual features — detects GAN artifacts, blending boundaries and texture anomalies.
STEP 04
👄
LipForensics
ResNet-50 analyses lip-region motion patterns. Generalisable across FaceSwap, NeuralTextures, Face2Face and more.
STEP 05
🔮
SigLIP v1 + v2
Google's vision transformers use sigmoid image-language pre-training for superior per-image semantic calibration.
STEP 06
🗳️
Ensemble Voting
All four models vote with weights 30/25/25/20. FFT frequency analysis adds a final anomaly cross-check.
Technology Stack

Production-grade AI/ML frameworks

🐍
Python + PyTorch
Core deep learning framework. All 4 models run on PyTorch with optional CUDA GPU acceleration.
🤗
HuggingFace Transformers
SigLIP v1 (google/siglip-base-patch16-224) and SigLIP 2 (google/siglip2-base-patch16-224) loaded via AutoModel.
👁️
OpenCV + MTCNN + timm
Video frame extraction via OpenCV, face detection via facenet-pytorch MTCNN, EfficientNet-B4 via timm.
⚡
FastAPI Backend
REST API with CORS support. Accepts image and video uploads. Returns per-model scores + ensemble verdict.
